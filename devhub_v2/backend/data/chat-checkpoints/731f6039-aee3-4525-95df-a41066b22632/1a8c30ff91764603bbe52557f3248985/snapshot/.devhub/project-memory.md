## Architecture Summary
An AI-powered, blockchain-enabled platform designed to modernize anti-corruption complaint handling. It features multi-channel submission (WhatsApp, IVR, Web, Mobile), NLP-driven categorization, credibility scoring, and predictive analytics. The system ensures transparency and accountability through immutable blockchain audit logs, automated SLA escalations, and real-time corruption heatmaps.
